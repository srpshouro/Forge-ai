FORGE AI - APK banano (shudhu mobile diye)

Lagbe: free GitHub account (github.com) ar Chrome.

1. GitHub e notun repository banao (nam: forge-ai). Public ba Private, duitoi cholbe.
2. Repository te: Add file > Upload files > ei zip extract kore index.html select koro > Commit changes.
3. Add file > Create new file. Nam er ghore lekho:  .github/workflows/build.yml
   (slash / dile folder nijei hoye jabe). Ei zip er build.yml er lekha (ba chat er code) paste koro > Commit changes.
4. Actions tab e jao. "Build APK" nijei chalu hobe (5-10 minute). Shobuj tick ashle oi run e click koro.
5. Niche Artifacts er "ForgeAI-apk" download koro. Eta zip, Files app diye extract koro.
6. app-debug.apk e tap koro > "Install unknown apps" allow koro > Install.

Note:
- Run fail korle (lal X), run khule error er last kichu line amake pathao.
- App er Download button share sheet kholbe. Sekhane Files ba "Save to device" bachai koro.
- Notun index.html upload korle (same nam e replace) APK abar nijei build hoy.
- Debug APK, Play Store er jonno noy. Play Protect warning dekhale "Install anyway" dao.

File permission: app kholle Android file access chaibe. Allow korle sob file Documents/ForgeAI folder e nijei save hoy. Download e chaple abar save hoy.
